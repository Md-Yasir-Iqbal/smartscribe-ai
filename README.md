# SmartScribe AI

**AI Text & PDF Summarizer and Simplifier**

SmartScribe AI is a Python-based application that uses Google's Gemini API to summarize, simplify, and extract key information from text and PDF documents.

It supports long documents through a paragraph/sentence-aware chunking pipeline and provides configurable output based on processing mode, length, tone, and format.

## Features

* **Text Summarization** — summarize pasted text with configurable output options
* **PDF Summarization** — extract and summarize multi-page PDF documents
* **Four Processing Modes**

  * Summary
  * Explain Simply
  * Student Mode
  * Key Takeaways
* **Configurable Output**

  * Very Short → Detailed
  * Simple → Professional tone
  * Paragraph, bullet-point, or numbered format
* **Long-Document Processing** — chunk → summarize → combine pipeline for larger documents
* **Document Insights** — calculated word count, compression percentage, and estimated reading-time savings
* **Session History** — revisit previous results during the current session
* **Export** — copy results or download them as `.txt` or `.md`
* **Error Handling** — handles invalid API keys, rate limits, quota errors, timeouts, corrupted PDFs, password-protected PDFs, and scanned/image-only PDFs
* **Structured AI Output** — Gemini responses are requested in JSON format containing the summary and key takeaways for consistent rendering

## Architecture

```text
User
  │
  ▼
Streamlit UI            (components/)
  │
  ▼
Application service      (services/summarizer.py)
  │  — decides: single-pass summary, or chunk → map → reduce
  ▼
Text / PDF processing     (services/text_processor.py, services/pdf_service.py)
  │
  ▼
Prompt construction       (prompts/)
  │
  ▼
AI service                (services/ai_service.py)
  │  — the ONLY module that calls Gemini
  ▼
Gemini API
  │
  ▼
Post-processing            (utils/metrics.py → Document Insights)
  │
  ▼
Result UI                  (components/result_view.py)
```

The application separates the UI, application logic, document processing, prompt construction, AI-service integration, and utility logic.

Gemini API calls are isolated inside `services/ai_service.py`, while the rest of the application communicates through the service layer.

## How It Works

### 1. Input Processing

Users can either paste text directly into the application or upload a PDF.

For PDFs, PyMuPDF extracts the document text. Files that are corrupted, password-protected, or contain no extractable text are rejected with specific errors.

SmartScribe currently does **not** perform OCR on scanned or image-only PDFs.

### 2. Text Processing

Extracted text is cleaned and validated before summarization.

For longer documents, the text is divided into logical chunks using paragraph and sentence boundaries rather than simply cutting the document at arbitrary character positions.

### 3. Summarization Pipeline

Shorter inputs can be processed in a single Gemini request.

Longer documents use a map-reduce style pipeline:

```text
Long Document
     │
     ▼
   Chunks
     │
     ▼
Individual Summaries
     │
     ▼
Combined Summaries
     │
     ▼
Final Coherent Summary
```

This allows the application to process documents that are too large for a practical single request.

### 4. Prompt Construction

Different prompts are used for summarization, simplification, and key-takeaway generation.

Prompts instruct the model to:

* Preserve important facts, names, numbers, and dates
* Use original wording
* Avoid unsupported information
* Follow the selected tone and output format

### 5. Structured Response

The AI service requests a structured JSON response containing the generated summary and key takeaways.

This allows the application to reliably separate and render the different output sections.

### 6. Document Insights

Metrics such as word count, reduction percentage, and estimated reading-time savings are calculated directly from the source and generated text.

These values are **computed by the application rather than generated by the LLM**.

## Getting Started

### Prerequisites

* Python 3.10+
* Google Gemini API key

### Installation

```bash
git clone <repository-url>
cd smartscribe-ai
pip install -r requirements.txt
```

### Environment Setup

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=your_supported_gemini_model
```

Keep your API key private and do not commit the `.env` file.

### Run Locally

```bash
streamlit run app.py
```

The application will open in your browser.

## Configuration

SmartScribe reads configuration from environment variables during local development and from Streamlit Secrets when deployed.

The API key is never hard-coded into the application.

The Gemini model is configurable through `GEMINI_MODEL`, allowing the application to use a supported model without changing the application code.

## Testing

The project includes unit tests for the deterministic parts of the application, including:

* Text cleaning
* Text chunking
* Word-count calculations
* Reading-time calculations
* Compression calculations
* Input validation
* PDF extraction
* Corrupted PDF handling
* Password-protected PDF handling
* Blank/scanned PDF handling

Tests do not require a real Gemini API key because the test suite focuses on the application's processing and validation logic rather than making live API requests.

Run:

```bash
pytest
```

For more detailed output:

```bash
pytest -v
```

## Limitations

* Scanned/image-only PDFs are not supported because OCR is not currently implemented.
* Session history is temporary and is cleared when the application session ends.
* The application depends on Gemini API availability, quotas, and rate limits.
* Summaries are generated by an LLM and should be reviewed when working with sensitive or critical information.
